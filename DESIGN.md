# Design System: Дашборд «Мария» — План/Факт

## 1. Overview

**Creative North Star: "Печать качества"**

Дашборд «Марии» — это не витрина, а рабочий стол руководителя, где каждый день решается один вопрос: «идём мы по плану или отстаём?». Смысловой центр системы — **золотая сургуч-печать процента выполнения плана**: тяжёлая монета с рифлёным рантом, которая загорается золотом при успехе и гаснет в тревожный винный при отставании. Всё остальное — тёплое кондитерское поле вокруг этой печати: глубокое какао-ганаш в тёмной теме, тёплая бумага в светлой, кремовый текст, винный функциональный акцент. Золото тратится точечно — оно означает достижение, а не украшение.

Система **служит задаче**: плотная спокойная сетка карточек, KPI-ряд сверху, графики ниже, воздух в шапке. Цвет несёт смысл (тренд, статус), а не декорирует. Читаемость плотных таблиц с цифрами важнее любого эффекта. Один оправданный смелый ход — стеклянные панели с мягким aurora-свечением фона — держит экран от вида дефолтного BI-шаблона, но не мешает данным.

Система **явно отвергает**: дефолтный AI-дашборд (Inter/Roboto, холодный сине-серый, hero-метрика с градиентом, одинаковые плитки icon+heading+text); «море красного» — заливку больших площадей фирменным вином; детский/мультяшный вид и эмодзи как визуальный язык; корпоративный холод (тёмно-синий + серый); стоковые дашборд-темплейты.

**Key Characteristics:**
- Золотая печать % выполнения — единственный «геройский» элемент; всё подчинено ей.
- Тёплая материальная палитра «Ганаш & золото», две темы, обе выверены по контрасту.
- Вино = сигнал (CTA/активное/ключевая цифра), не фон.
- Стекло + aurora — осознанная сигнатура, не дефолтный декор.
- Данные честные: нет цифры → «н/д»/«—»; оценка помечена.

## 2. Colors

Тёплая материальная палитра: какао и крем как поле, вино как функциональный голос, золото как редкая печать достижения. Значения ниже — светлая тема (дефолт); тёмная тема даёт свои значения тех же ролей (см. Named Rules).

### Primary
- **Винный акцент** (#8A2A3B светлая / #C7566A тёмная): единственный функциональный акцент. CTA-кнопки, активный пункт навигации, активная вкладка (подчёркивание), ключевая цифра, тренд-стрелки, фокус-кольцо. На нём читается светлый текст (≈8:1 на бумаге).

### Secondary
- **Золото-печать** (#8A6B12 текст / гардиент #F1D779→#CDA62B→#957210 на медали): СИГНАТУРА. Печать % выполнения плана, золотой рул героя, состояние «план выполнен». Тратится точечно — золото = достижение. Как мелкий текст берётся контраст-безопасный #8A6B12 (светлая) / #C9A227 (тёмная); сама медаль красится собственным многослойным градиентом, не токеном.

### Neutral
- **Ганаш-ink** (#2A211C светлая / #F3ECE4 крем тёмная): основной текст.
- **Тёплая бумага** (#F6F1E8 светлая / #161210 глубокое какао тёмная): фон приложения — НЕ чисто-белый и НЕ холодный.
- **Крем-поверхность** (#FFFDF9 светлая / #211A16 тёмная): карточки, панели, инпуты (`--glass`).
- **Таупе-muted** (#7A6A5C / #B3A595): вторичный текст, подписи вкладок в покое.
- **Таупе-hint** (#6E6152 / #9C8E7E): мелкие лейблы форм, таймстемпы (выверен под AA для 10–11px).
- **Хэйрлайн** (#E7DECF / #382C22): разделители, границы карточек 1px.

### Semantic
- **Олива-успех** (#4C7439 / #8FA86B): «план выполнен», положительный YoY.
- **Янтарь-внимание** (#9C5F1E / #D6A24A): предупреждение, «на грани».
- **Оксбладь-danger** (#A33A3A / #D06A6A): реальные алерты — ВСЕГДА с иконкой/текстом, не цветом одним (близок к бренд-вину).

### Named Rules
**Правило Печати.** Золото появляется только как знак достижения — печать % выполнения, «план выполнен», топ-по-выручке. Никогда как фон, разделитель или декоративная обводка. Его редкость и есть смысл.

**Правило Сигнала.** Винный акцент занимает ≤10% любого экрана. Заливать вином большие площади запрещено — сигнал живёт в колонках «Тренд/YoY» и на одном CTA, а не в сырой заливке.

## 3. Typography

**Display Font:** Prata (с Georgia, serif) — засечка-дисплей сайта maria-irk.ru.
**Body/UI Font:** Onest (с system-ui) — гротеск интерфейса.
**Data Font:** JetBrains Mono (с Consolas) — цифры и KPI.

**Character:** Контраст на оси засечка↔гротеск: Prata даёт кондитерской нарядность в заголовках, Onest — спокойную рабочую читаемость в плотном UI. Числа уходят в JetBrains Mono с `tabular-nums`, чтобы колонки план/факт не «плясали». Запрещённые лица (Inter/Inter Tight, Roboto sans, Arial, Space Grotesk) вычищены — они читаются как «дефолт».

### Hierarchy
- **Display** (Prata 400, clamp(26–46px), lh 1.1): hero-заголовок, название бренда «Мария», заголовок PIN-экрана. Дозированно.
- **Headline** (Onest 700, 20px): крупные заголовки блоков.
- **Title** (Onest 700, 16px): `.section-label` — титул секции (промоутится в role=heading/h2).
- **Body** (Onest 400, 14px, lh 1.5): основной текст, подписи; проза ≤ 65–75ch, таблицы данных плотнее.
- **Label** (Onest 600, 13px): микро-лейблы, бейджи.
- **Data** (JetBrains Mono 500, clamp(24–34px), ls -0.02em): значения KPI.

### Named Rules
**Правило Табличных Цифр.** Любое числовое значение в колонках/KPI — моно с `font-variant-numeric: tabular-nums`. Дисплейный шрифт в плотных таблицах данных запрещён.

## 4. Elevation

Гибрид: тёплые мягкие тени + осознанное **стекло**. Панели/карточки — полупрозрачное стекло (`backdrop-filter: blur(28px) saturate(180%)`) поверх фона с медленным aurora-свечением (радиальные золото-винные блобы). Это фирменный «один смелый ход», а не дефолтный glassmorphism: в светлой теме blur приглушается, карточки становятся плотными (~непрозрачными), чтобы плотные таблицы читались.

### Shadow Vocabulary
- **Glow-card светлая** (`box-shadow: 0 1px 2px rgba(42,33,28,.05), 0 2px 10px rgba(42,33,28,.07)`): базовая тень карточки — hairline-подъём, не «драма».
- **Glow-card тёмная** (`box-shadow: 0 2px 10px rgba(0,0,0,.45), inset 0 1px 0 rgba(255,255,255,.035)`): глубина через тень + верхний внутренний блик (стекло).
- **Ховер-лифт** (`transform: translateY(-1..-3px)` + усиление тени): карточки/кнопки слегка приподнимаются; без резких теней.

### Named Rules
**Правило Читаемого Стекла.** Стекло допустимо, только если поверх него данные остаются читаемыми. На плотных таблицах и мелких числах blur приглушается или снимается — эффект никогда не побеждает цифру.

## 5. Components

### Buttons
- **Shape:** мягкие скругления (radius 12px, `{rounded.md}`).
- **Primary:** вино `{colors.wine-accent}` + белый текст, padding 10×22px, weight 600, мягкая винная тень-glow (`0 6px 18px -6px accent`). Hover — `translateY(-1px)` + усиление glow; active — `scale(.98)`.
- **Secondary / Ghost:** крем-поверхность + 1px hairline + ink-текст, лёгкий `backdrop-blur(8px)`. Вторичный вес (500).

### Chips / Badges
- **Style:** токенные классы `.b-good / .b-warn / .b-info / .b-neutral` — мягкая подложка `*-soft` + цвет-текст соответствующей семантики. Переиспользовать, не плодить инлайны.
- **Scope-бейджи:** `.mkt-scope.dyn` (вино на accent-soft) для live-данных, `.mkt-scope.now` (золото на gold-soft) для актуального периода.

### Cards / Containers
- **Corner Style:** 16px (`{rounded.lg}`).
- **Background:** крем-поверхность `--glass`; KPI-состояния (`.kpi.good/.warn/.bad`) — лёгкий радиальный тинт семантики в углу + `--glass`.
- **Shadow Strategy:** `--glow-card` (см. Elevation) + `backdrop-blur(28px)`.
- **Border:** 1px hairline. **Internal Padding:** `--space-6` (карточка), KPI 20×18px.
- **Вложенные карточки запрещены.**

### Inputs / Fields
- **Style:** крем-поверхность + 1px hairline, radius 10px (`{rounded.sm}`), `backdrop-blur(8px)`.
- **Focus:** border → вино + винное кольцо `box-shadow 0 0 0 3px accent-soft`; глобальный `:focus-visible` — `outline: 2px solid accent`.
- **Плейсхолдеры:** `var(--muted)` (AA-контраст), не холодный серый.

### Navigation
- **Sidebar-nav** (`.nav-btn`): вертикальный список, иконка+текст; активный — акцентный. Мобильный — выезжающий drawer (hamburger 44×44 + backdrop, `body.nav-open{overflow:hidden}`).
- **Вкладки** (`.atab`): подчёркивание — прозрачный `border-bottom 2px`, muted-текст; активная = вино-текст + винное подчёркивание + weight 600. Роли `tablist/tab` + `aria-selected` + навигация стрелками.

### Золотая печать (сигнатура)
`.summary-hero .hero-headline b` — % выполнения плана как **глянцевая золотая медаль**: `inline-flex` круг min 3.1em, моно-цифра, многослойный радиальный градиент золота (#F1D779→#CDA62B→#957210), блик, тень-glow, рифлёный сургуч-рант через `repeating-conic-gradient` + `mask`. При отставании (`.hero-bad`) монета гаснет в таупе, а рант становится винным с тревожным свечением. Это смысловой центр всего дашборда.

## 6. Do's and Don'ts

### Do:
- **Do** держать золото только как печать достижения (% выполнения, «план выполнен», топ-по-выручке) — Правило Печати.
- **Do** держать вино ≤10% экрана: CTA/активное/ключевая цифра/тренд — Правило Сигнала.
- **Do** давать числам `JetBrains Mono` + `tabular-nums`; текст/UI — `Onest`, дисплей — `Prata`.
- **Do** показывать пустое как «н/д»/«—», а оценку помечать словом «оценка» — выдуманное число хуже пустого.
- **Do** держать контраст ≥4.5:1 (мелкий) / ≥3:1 (крупный) в обеих темах; danger — всегда с иконкой/текстом, не цветом одним.
- **Do** приглушать/снимать blur на плотных таблицах — Правило Читаемого Стекла.

### Don't:
- **Don't** заливать большие площади фирменным вином («море красного»).
- **Don't** использовать Inter/Inter Tight, Roboto (sans), Arial, Helvetica, Space Grotesk, Open Sans, Lato — читаются как дефолт.
- **Don't** ставить эмодзи как визуальный язык — для этого бренда это «дёшево»; иконки рисованные line-SVG.
- **Don't** делать hero-метрику с градиент-текстом, одинаковые плитки icon+heading+text, uppercase-эйсбрау над каждой секцией, нумерованные маркеры 01/02/03.
- **Don't** использовать `border-left/right` >1px как цветную полосу-акцент; `background-clip:text` + градиент (gradient text).
- **Don't** уходить в холодный сине-серый корпоратив или дефолтный AI-BI-шаблон.
- **Don't** вкладывать карточки в карточки.
